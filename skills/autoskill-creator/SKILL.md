# Company AutoSkill Creator

Turn repeated or discovered Company work into reusable **company-local** operational skills. This is Business Learning, not KAST.

## Law

`experience / observed process → registry search → reuse existing OR create Company Skill → SkillGene → verified outcomes → challenger/champion OR silent/quarantine`

1. Search the Company/global skill catalog before creating a new skill. Prefer an existing compatible skill when it already covers the process.
2. If the process is specific to the Company, create a `company-skill-definition` CompanyAsset with sanitized instructions and evidence references.
3. Create/attach a `skill-installation` asset to the responsible department.
4. Represent learning/evolution with `CorporateGene(type=skill)`. Do not invent another candidate/promoted lifecycle.
5. Outcomes, confidence, cost and incidents belong to the Company SkillGene fitness, not to the global skill manifest.
6. Raw conversations, credentials, secrets and unbounded tool output are forbidden in skill definitions/evidence.
7. Skills never grant authority, budget or credentials. They describe how to perform work inside existing grants.
8. A company-local skill can remain private forever. If evidence later shows it is generic and valuable across Companies, propose a separate global-catalog promotion through KAST; KAST governs the shared system change, not ordinary Company learning.

## Progressive disclosure

`catalog metadata → match → load one selected skill body → execute → verify outcome`

Do not preload the whole catalog into model context.
